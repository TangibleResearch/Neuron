# Neuron32 instruction set

This is the human-readable companion to Nemu's executable reference model
(`src/isa.rs`, `src/cpu.rs`, `src/assembler.rs`, `src/matrix.rs`,
`src/scalar_alu.rs`, `src/mac.rs`) — Nemu remains the spec of record; this
document is generated by reading it, not by guessing. Every instruction
length below was cross-checked byte-for-byte between Nemu's assembler
(`src/assembler.rs`'s `OperandLayout::instruction_size`) and the RTL's own
decode table (`rtl/decode.sv`) and the two agree exactly, opcode for
opcode — no discrepancy found there.

Only instructions Nemu actually defines opcodes for are documented.
Vector (V0-V7) and predicate (P0-P3) registers exist as struct fields in
Nemu's `NeuronCpu` but **no opcode reads or writes them** — there is
nothing to document semantically, and nothing implemented in `rtl/`.

## Registers

| Register | Width | Reset value | Notes |
|---|---|---|---|
| R0-R15 | 32-bit, unsigned storage | `0` | General purpose. R0 has no special hardware behavior (not hardwired zero) — it's an ordinary register. |
| PC | 32-bit | `0` | Byte address of the next instruction to fetch. |
| SP | 32-bit | `MEM_SIZE` (1024 in every current target) | Stack grows down: `PUSH`/`CALL` decrement by 4 first, `POP`/`RET` increment by 4 after. |
| FP | 32-bit | `0` | Declared and reset-defined in both Nemu and the RTL, but **no opcode reads or writes it**. Architecturally present, currently unused by anything in `src/isa.rs`. |
| STATUS | 32-bit (4 bits meaningful) | `0` | See below. |
| M0-M3 | 4x4 array of 32-bit signed cells each | all cells `0` | See "Matrix registers" below. |
| MAC accumulator | 32-bit signed | `0` | Not a numbered register; addressed only via `MAC`/`MACCLR`/`MACREAD`. |

Little-endian throughout: a 32-bit memory access at address `A` occupies
bytes `A` (LSB) .. `A+3` (MSB); a 32-bit immediate in an instruction
encoding is likewise stored LSB-first.

## STATUS flags

| Bit | Flag | Set by |
|---|---|---|
| 0 | ZERO | Any instruction whose flag-update mode includes Z (see per-instruction table). |
| 1 | NEGATIVE | Any instruction whose flag-update mode includes N. |
| 2 | CARRY | `ADD`/`SUB`/`MUL`/`DIV`/`MOD`, `CMP`. Meaning varies by opcode — see notes. |
| 3 | OVERFLOW | `ADD`/`SUB`/`MUL`/`DIV`/`MOD` only. |

A flag not listed as updated by an instruction **holds its previous
value** (`isa_pkg::FLAG_MODE_NONE`/an instruction with no flag-update
call in Nemu) — it is never implicitly cleared.

## Instructions

Operand byte layout is given as bytes after the 1-byte opcode, in
encoding order. `Rn` = 4-bit scalar register selector (encoded as a full
byte in the instruction stream; only the low 4 bits are architecturally
meaningful — see `docs/EXCEPTIONS_AND_UNDEFINED_BEHAVIOR.md` for what an
out-of-range encoded value does). `Mn` = 2-bit matrix register selector,
same story. `imm32`/`addr32` = 4-byte little-endian.

| Mnemonic | Opcode | Size | Operands | Semantics | Flags |
|---|---|---|---|---|---|
| `MOVI` | `0x10` | 6 | `dst, imm32` | `dst = imm32` | Z,N from `imm32` |
| `MOV` | `0x11` | 3 | `dst, src` | `dst = src` | none |
| `ADD` | `0x20` | 4 | `dst, a, b` | `dst = a + b` (wraps) | Z,N,C,V — C = unsigned carry-out; V = signed overflow |
| `SUB` | `0x21` | 4 | `dst, a, b` | `dst = a - b` (wraps) | Z,N,C,V — C = `a >= b` unsigned (i.e. "no borrow"), not a raw borrow flag; V = signed overflow |
| `MUL` | `0x22` | 4 | `dst, a, b` | `dst = (a * b)[31:0]` (wraps) | Z,N,C,V — C and V are the *same* value: whether the full 64-bit product didn't fit in 32 bits |
| `DIV` | `0x23` | 4 | `dst, a, b` | `dst = a / b` (unsigned) | Z,N,C,V — C=V=0 always. **`b==0`: returns 0, does not trap** — see `docs/EXCEPTIONS_AND_UNDEFINED_BEHAVIOR.md` |
| `MOD` | `0x24` | 4 | `dst, a, b` | `dst = a % b` (unsigned) | Z,N,C,V — C=V=0 always. **`b==0`: returns 0, does not trap** |
| `AND` | `0x30` | 4 | `dst, a, b` | `dst = a & b` | Z,N |
| `OR` | `0x31` | 4 | `dst, a, b` | `dst = a \| b` | Z,N |
| `XOR` | `0x32` | 4 | `dst, a, b` | `dst = a ^ b` | Z,N |
| `NOT` | `0x33` | 3 | `dst, src` | `dst = ~src` | Z,N |
| `SHL` | `0x34` | 4 | `dst, src, amt` | `dst = src << (amt & 31)` | Z,N |
| `SHR` | `0x35` | 4 | `dst, src, amt` | `dst = src >> (amt & 31)`, logical (unsigned) shift | Z,N |
| `LOAD` | `0x40` | 3 | `dst, addr_reg` | `dst = mem32[Rn(addr_reg)]` | none |
| `STORE` | `0x41` | 3 | `addr_reg, src` | `mem32[Rn(addr_reg)] = Rn(src)` | none |
| `PUSH` | `0x50` | 2 | `src` | `SP -= 4; mem32[SP] = Rn(src)` | none |
| `POP` | `0x51` | 2 | `dst` | `dst = mem32[SP]; SP += 4` | none |
| `CMP` | `0x60` | 3 | `a, b` | Computes `a - b`, discards the value, updates flags only | Z,N from `a-b`; C = `a >= b` unsigned; V untouched |
| `JMP` | `0x70` | 5 | `addr32` | `PC = addr32` (unconditional) | none |
| `JZ` | `0x71` | 5 | `addr32` | `if ZERO: PC = addr32` | none |
| `JNZ` | `0x72` | 5 | `addr32` | `if !ZERO: PC = addr32` | none |
| `CALL` | `0x80` | 5 | `addr32` | `SP -= 4; mem32[SP] = PC (return address); PC = addr32` | none |
| `RET` | `0x81` | 1 | — | `PC = mem32[SP]; SP += 4` | none |
| `MAC` | `0x82` | 3 | `a, b` | `ACC = ACC + (INT8(Rn(a)) * INT8(Rn(b)))` (32-bit wrapping accumulate) | none |
| `MACCLR` | `0x83` | 1 | — | `ACC = 0` | none |
| `MACREAD` | `0x84` | 2 | `dst` | `dst = ACC` | Z,N from `ACC` |
| `MMUL` | `0x90` | 4 | `dst_m, a_m, b_m` | `dst_m = a_m × b_m` (4x4, INT8 inputs, INT32 accumulate per cell) | Z = all 16 result cells zero; N=C=V=0 always |
| `RELU` | `0x91` | 2 | `reg` | `reg = (reg < 0) ? 0 : reg` (in place, signed comparison) | Z,N from the result |
| `MSET` | `0x92` | 5 | `m, row, col, val` | `m[row][col] = sign_extend_32(INT8(val))` | none |
| `OUT` | `0xA0` | 2 | `src` | Emits the low 8 bits of `Rn(src)` as one byte on the output stream | none |
| `HALT` | `0xFF` | 1 | — | Stops execution (terminal until `reset`) | none |

### Notes on specific instructions

- **`MUL`'s carry/overflow.** Both flags report the exact same condition
  (`overflowing_mul` not fitting in 32 bits) — there's only one
  "something didn't fit" fact for a multiply, reported on both bits. This
  matches `src/scalar_alu.rs::mul` exactly (`carry: overflow, overflow`).
- **`SUB`'s carry is not a borrow flag.** It's `a >= b` (unsigned) — carry
  set means *no* borrow occurred. Matches `!borrow` from Rust's
  `overflowing_sub` in `src/scalar_alu.rs::sub`, and `CMP`'s carry uses
  the identical convention.
- **`SHL`/`SHR` mask the shift amount to 5 bits** (`amt & 31`), matching
  `wrapping_shl`/`wrapping_shr` in `src/issuer.rs` exactly — a shift
  amount of 32 or more does not zero the result or panic, it wraps to
  `amt mod 32`.
- **`MAC`'s operands are truncated to INT8**, not range-checked: `Rn(a)`
  and `Rn(b)` are each read as full 32-bit registers, then only the low 8
  bits are used, reinterpreted as signed. Matches Nemu's `as i8` cast in
  `cpu.rs`'s `OP_MAC` arm exactly (a C-style truncating cast, not a
  checked conversion).
- **`MMUL`'s matrix inputs are truncated to INT8 from each 32-bit cell**,
  which Nemu instead panics on if a cell doesn't fit — a deliberate
  hardware deviation, see `docs/EXCEPTIONS_AND_UNDEFINED_BEHAVIOR.md`.
  `MSET`'s immediate is always INT8-range by construction (the assembler
  rejects anything else), so this only matters for a matrix register
  previously written by another `MMUL`.
- **`RELU` compares the full 32-bit value as signed**, not just the sign
  bit of some narrower type — `reg < 0` means bit 31 set, ordinary two's
  complement.
- **`OUT` truncates to the low 8 bits** of the source register
  unconditionally (`value & 0xFF` in Nemu, `reg_read_a[7:0]` in RTL) —
  not range-checked.
- **Absolute addresses (`JMP`/`JZ`/`JNZ`/`CALL`) are unsigned 32-bit,
  byte addresses, little-endian**, not PC-relative offsets.

## Stack

Grows downward from `SP = MEM_SIZE` at reset. `PUSH`/`CALL` decrement
`SP` by 4 *before* writing; `POP`/`RET` read at the current `SP` *before*
incrementing by 4 after — standard full-descending-stack discipline.
Neither Nemu nor the RTL currently detects underflow/overflow at the
hardware level — see `docs/EXCEPTIONS_AND_UNDEFINED_BEHAVIOR.md`.

## Matrix registers

Four registers (M0-M3), each a 4x4 array of independent 32-bit signed
cells — not a packed INT8 tile in storage. `MSET` writes one cell at a
time from a sign-extended INT8 immediate. `MMUL` reads two matrix
registers as 4x4 INT8 tiles (truncating each 32-bit cell to its low 8
bits — see above), computes a standard 4x4 matrix product with 32-bit
accumulation per output cell (`C[r][c] = sum_k A[r][k] * B[k][c]`,
wrapping on 32-bit overflow, matching `i32::wrapping_add` in
`src/mac.rs`/`src/matrix.rs` and `rtl/mac.sv`'s plain fixed-width
addition), and bulk-writes the full 4x4 INT32 result to the destination
register in one shot. A destination register that's also a source
register is safe: the read happens throughout the whole multi-cycle
run, the write happens only on the completion cycle, after the last
read — see `docs/MICROARCHITECTURE.md`'s matrix-engine timing and
`tb/matrix_tb.sv`'s dest==src check.
